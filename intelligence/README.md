# Phase 9 — Intelligence

Strategic operational intelligence for TeamOS.

Rules:
- Humans remain decision-makers.
- Outputs are explainable (`ExplainabilityLog`) and auditable.
- Intelligence generates **recommendations**, not autonomous execution.

Implementation lives primarily in:
- `modules/intelligence/*`
- `modules/prediction/*`
- `modules/risk/*`

Surfaced via internal APIs under `app/api/intelligence/*`.
